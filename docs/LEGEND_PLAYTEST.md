# 自分の設定で、かつての絶望を越える

## 今回の狙い

全10能力は既に個別の戦闘効果を持つ。一方、習得後に同じ事件へ挑めず、組み合わせの強さを比較する場がない。成功した操作も敵の行動ログに埋もれる。この二点はコードで確認できる課題だった。「繰り返したくなるか」は人による評価が必要で、今回の自動テストからは断定しない。

今回の体験は「覚える → 設定を試す → 自分の判断で突破する → その証をノートへ残す」。能力数や説明量を増やすより、既存の能力を使いこなす目的を作る。

- 習得済みの9事件に、追憶戦として挑める。物語の前置きを繰り返さず戦闘から開始する。
- 各事件に任意の「設定証明」を一つ用意。条件を満たして勝つと、系譜に金色の証明済表示が付く。
- 条件を逃しても通常の勝利で能力を習得する。証明を取るために進行をやり直す必要はない。
- 追憶戦では事件の代表能力を必ず使用可能にし、それ以外はノートで選んだ設定を持ち込む。戦闘終了後は元の選択に戻る。
- 追憶戦は記述点と日数を増やさない。最少手数・最高残存存在・勝利回数・証明済状態だけを記録する。各最高記録は別の挑戦で更新できる。
- 敗北画面から同じ条件ですぐ再戦できる。初回の覚醒演出や物語を毎回読み直させない。

## 面白さが生まれる場面

魔眼の事件では、最初から見抜いて安全に戦うこともできる。より使いこなすなら、接近中に集中し、飛びかかってくる瞬間に魔眼を開く。敵の攻撃を見切り、集中した攻撃を弱点へ返す。テスト上では前者は4手・残存存在63、後者は3手・残存存在72で勝利した。後者だけに「見切って勝つ」の証明が付く。

黒龍の事件は、強打を防ぎ、硬直した殻を破壊すれば証明できる。あとから魔眼を習得して戻ると、魔眼で継ぎ目を見つけ、硬直を待たず黒龍で殻を砕ける。「魔眼 × 黒龍・死線穿孔」と実際に起きた効果を表示し、昔のノートの一文が意味を持った瞬間を残す。強打と同時に仕掛けるなら被害は受ける。早さと安全の判断は残る。

詠唱は防御ボタンを押しただけでは証明しない。実際に妨害を防ぎ、二節以上を解き放ち、勝って初めて証明する。上位の終焉ノ詠唱も、敵を倒しただけなら行動封じの証明にはならない。実際に敵の行動を封じる必要がある。

## 表示と操作

- 主操作は専用技・攻撃・防御・集中の4つ。
- 成功時は短い厨二的な技名、ノートの一文、実際の効果を戦闘内に表示する。操作を止める追加カットインは入れない。
- 与えた傷・受けた傷を毎手表示。詠唱中断時は失敗と対策を表示する。全文ログは「設定・直前の一手」に残す。
- 大きい画面は敵を表示。収まらなければ敵を省いた小さい配置、それでも収まらなければスクロールへ切り替える。アクセシビリティ用の大きな文字は最初からスクロールを許可する。
- 獲得画面は能力名、ノートの一文、今回の結果、次へ進むボタンを系譜より先に表示する。
- 事件の前置きでも、殻・不可視・静寂の敵の外見を区別する。

## 保存と互換性

`chronicle.prototype.v1`と`chronicle.introduction.v4`を維持。Gameのrecords、BattleStateのproof、TrialProgressのisReplayはいずれもoptionalで、以前のセーブはそのまま読める。古い戦績を推測で証明済にはしない。以前の戦闘途中データはその戦闘の敵・ルールを維持する。追憶戦を始めると現在のカタログのルールで戦う。

証明は戦闘中に進行状態として保存し、勝利時に初めて戦績へ記録する。敗北・再戦では戦闘中の証明を消す。追憶戦で敗北して再戦しても、新規習得報酬を再獲得しない。新しいSwiftファイルをアプリに登録する必要がないよう、共有ロジックは既存のChronicle.swiftに置く。

## 作者のiPhone確認

1. 魔眼の事件で「集中 → 飛びかかりに魔眼 → 攻撃」。見切りと被害0が伝わるか。
2. 詠唱の事件で妨害時に詠唱し、中断と対策が読めるか。敗北後、一押しで再戦できるか。
3. 一度勝ち、ノートの「追憶戦・かつての絶望を越えろ」を開く。再挑戦後、手数・証明・系譜の印が更新されるか。
4. 魔眼を持って黒龍の追憶戦へ戻り、見抜いてから殻を砕く。組み合わせが一つの技になったと感じるか。
5. 妨害への備えや詠唱が残る途中でアプリを終了し、再開して続ける。
6. 小さいiPhone、文字拡大、VoiceOver、視差効果を減らす設定で、行動ボタンと直前の結果を確認する。

第三者には攻略手順を先に教えず、「どの設定がどう役立ったか」「次に何を変えて再挑戦したいか」を自分の言葉で答えてもらう。最初の行動までの秒数、各戦闘の秒数・手数、説明を開いた回数、再挑戦を自分から選んだかを記録する。ゲーム内の手数と、人間が考える時間は区別する。今回、実機での時間計測や第三者評価は未実施。

## Macで今回の版を試す

この変更は作業ブランチ`codex/prove-your-legend`。mainへの自動同期だけでは入らない。

Xcodeでアプリを停止してから、ターミナルで以下を実行する。

```sh
cd /Users/koheinishihara/Kurorekishi
bash scripts/uninstall-mac-sync.sh
git status --short
```

`git status --short`が空なら、次へ進む。変更が表示される場合は削除せず内容を確認する。

```sh
git fetch origin codex/prove-your-legend:refs/remotes/origin/codex/prove-your-legend
git switch --track origin/codex/prove-your-legend
open iOS/Chronicle.xcodeproj
```

すでにこのブランチを作った場合は`git switch codex/prove-your-legend`と`git pull --ff-only`で更新する。XcodeでChronicleとiPhoneシミュレータを選び、Cmd+R。既存の進行のまま追憶戦を試せる。「書き直す」による初期化は不要。
