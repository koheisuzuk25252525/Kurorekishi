# 自分の設定に目覚める・試遊ガイド

## 今回の覚醒

初回の漆黒拳と、全9事件の覚醒に同じ操作可能な導線を入れた。

1. 昔のノートに書いた一文を読む。「ああ。これは、俺の設定だ。」を自分で選ぶ。
2. 封印を右へなぞって解除する。右腕は包帯、魔眼は禁じられた視界、詠唱は消された言葉として表示する。
3. 紙の色が覚醒世界の色へ変わり、文字と紋章が光る。ルビ付きの能力名と、戦闘でできることが現れる。
4. 「この力を、解き放つ」で、初回は漆黒拳の発動へ、各事件では新能力を使う戦闘へ進む。

右腕は紅、魔眼は青、詠唱は金で区別する。覚醒中の2.6秒の強制待機を操作へ置き換えた。スライドは途中で離すと戻り、8割以上で解放する。同じ操作ができるボタンを常設し、VoiceOverやジェスチャーが苦手な人にも対応する。動きを減らす設定では回転・拡大・遷移アニメーションを止める。

途中で閉じても力を取得せず、ノートの一文へ戻る。新能力の本取得は従来通り事件への勝利時。覚醒の画面を連打しても、発動処理は一回だけ実行する。アプリ終了時は既存の事件の危機から再開できる。封印をなぞった途中の位置は保存しない。

## 既存セーブを残してテストプレイ

画面上部の「覚醒から試遊」を押す。戦闘中なら「その他 → 覚醒から試遊（セーブはそのまま）」を選ぶ。

- 最初の危機から始まり、そのまま3系統と全10能力まで遊べる。
- 「試遊中・進行は保存されません」と表示される。
- 「試遊を終える」で元の画面・本編の進行へ戻る。
- 試遊内で「書き直す」を押しても本編は変更しない。
- 試遊は一時的な進行。終了・アプリ終了後に試遊の続きから再開する機能はない。本編の途中保存は維持する。

本編では`chronicle.prototype.v1`と`chronicle.introduction.v4`を引き続き利用する。試遊モードの読み書きはSessionPersistenceで分離し、保存済み進行を読み込まず、保存キーへ書き込まない。

## Macに今回の版を取り込む

Xcodeで実行中のアプリを停止。ターミナルへ以下をコピーする。既存mainは変更しない。ローカル変更と競合した場合はGitが停止するので、ファイルを削除したりresetしたりせず、その表示を確認する。

```sh
cd /Users/koheinishihara/Kurorekishi &&
git fetch origin codex/awaken-your-power:refs/remotes/origin/codex/awaken-your-power &&
git switch codex/awaken-your-power &&
git merge --ff-only origin/codex/awaken-your-power &&
open iOS/Chronicle.xcodeproj
```

初回の`git switch`は取得した同名のリモートブランチから作業ブランチを作る。既にある場合はそれに切り替わる。Gitの自動追跡が無効な環境で初回の切り替えに失敗した場合は、`git switch --track origin/codex/awaken-your-power`を使う。

Xcodeの上部でChronicleとiPhoneシミュレータを選び、Cmd+R。起動したゲームで「覚醒から試遊」を押す。この版は作業ブランチなので、main用の自動同期だけでは入らない。自動同期スクリプトはmain以外では処理をスキップする。

## 確認する場面

- 殴っても効かない危機 → ノート → 自分で封印解除 → 漆黒拳 → 習得1/10。
- スライドを途中で離してやり直す。ボタンでも同じように解除できる。
- 黒龍・魔眼・詠唱の事件で、色・紋章・一文・能力名が変わる。
- 試遊を終了し、本編の進行、選択中の能力、戦闘中ならHPと手番が元のままである。
- 文字拡大、VoiceOver、動きを減らす設定、小さいiPhoneで全操作へ到達できる。
