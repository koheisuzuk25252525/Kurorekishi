習得した能力で同じ事件に再挑戦できず、成功した判断もログに埋もれていた。習得済み事件へすぐ戻れる「追憶戦」と、能力を使いこなして勝つ任意の「設定証明」を追加する。

例えば魔眼は、飛びかかりに合わせて見切り、その戦いに勝つと証明される。条件未達でも通常の勝利で能力を習得できる。魔眼と黒龍で殻を砕いた瞬間には、複合技の名称・ノートの一文・実際の効果を戦闘内に表示する。

- 全9事件に証明条件。勝利時に証明・最少手数・最高残存存在を保存し、系譜にも反映。
- 追憶戦は事件の能力と選択済みの設定で戦い、記述点や日数を増やさない。元の選択を復元する。
- 敗北後は直接再戦可能。戦闘中の証明は敗北時には戦績にならない。
- 戦闘の成功・詠唱中断・与えた傷と受けた傷を表示。小画面では敵を省いた配置へ切り替える。
- 保存キーと導入v4を維持。追加状態はoptionalで旧セーブを読み込む。
