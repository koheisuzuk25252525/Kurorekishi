# 禁書・終焉ノ能力系譜

現在の10能力を、効果・獲得事件・詳細画面を含めて実装した版。
能力数を増やす前に、既存の終端を「名前だけの上位互換」で終わらせない。
全9事件に敵の行動予兆を設定し、全系統の完走をテストする。

| 段階 | 右腕・龍腕ノ封縛 | 魔眼・因果ノ魔眼 | 詠唱・終焉ノ言霊 |
| --- | --- | --- | --- |
| 起点 | 第一拘束解除：漆黒拳と受け止める力 | ← 共通の起点 | ← 共通の起点 |
| 覚醒 | 黒龍顕現：隙や継ぎ目へ龍顎、防御破壊 | 魔眼開放：看破と襲撃の見切り | 長文詠唱：妨害に備えて詠唱を重ねる |
| 禁式 | 神喰らいの右腕：敵の攻撃を吸収し次の技へ | 因果を視る眼：二手先の予兆と強打の見切り | 終焉ノ詠唱：二節以上で敵の行動を二回封じる |
| 終式 | 終焉を掴む手：吸収した力を三倍にして防御ごと貫く | 世界の理を視る眼：一戦一度、敵の一手を消し弱点を刻む | 真名解放：三節で発動し、全防御貫通・殻の消去・存在回復 |

ツリーの金色の封印が各系統の終式。全てタップして、ルビ、詠唱、現実の効果、解放する事件、先に眠る力を読める。
未習得の能力も閲覧可能。通常の進行画面には文章を増やさず、読みたいときだけ開く。
10能力の全解放で「十の封印、完全解放」を表示する。元の3基礎設定は引き続き設定強度に寄与する。

## 戦闘操作

4ボタンと系統切替を維持。専用行動は状況と選択した設定に合わせて変わる。

- 右腕：敵が攻撃する手には神喰らい。技残数1で被害を0にし、最大60の力を保存する。
  次の攻撃技に保存した力が加算される。終式を選択していれば「終焉を掴む手」が現れ、保存した力の3倍を追加して防御・不可視を貫く。
- 魔眼：通常は看破。因果の眼を選択していると飛びかかりだけでなく強打も見切れる。
  世界の理の眼を選択していると、危険な手には「書換え」が現れる。一戦一度だけ、その敵行動を無効化する。
- 詠唱：二節以上の解放で終焉ノ詠唱が発動し、その手の敵行動から二回を封じる。
  静寂の間に次の詠唱を作れる。真名を選択し三節まで重ねると、解放ボタンが真名解放へ変わる。
  真名解放は存在を24回復（最大100）し、殻や不可視を無視する。

上位の設定も付け外せる。神喰らいで力を溜めて終焉の手で使うなど、組み合わせる設定を選ぶ。
各終式の前提設定は習得時に一緒に選択されており、通常の進行ではそのまま使用できる。

## 保存と検証

`chronicle.prototype.v1`と`chronicle.introduction.v4`を維持。
追加状態はBattleState内のoptionalなascensionに保持するため、前回の戦術版の途中セーブも読み込める。
蓄えた力、未来書換えの使用回数、静寂の残り手数も保存する。
旧mainから保存されていた事件は、保存時の敵設定のまま進む。新しい予兆は次に開始した事件から適用される。

公式Swift 6.0.3のLinuxコンテナで28件のXCTestが全件成功。
Swiftのテストは吸収・力の消費・強打の見切り・書換え回数制限・静寂・真名・保存互換性を個別に確認し、
既存の全事件完走・各系統単独完走も維持。iOSビルドと操作確認はMacが必要。

試遊するブランチはcodex/complete-ability-tree。前回の戦闘改善も含んでいる。mainは変更しない。

```sh
cd /Users/koheinishihara/Kurorekishi
bash scripts/uninstall-mac-sync.sh
git status --short
# 変更がないことを確認してから、以下を実行する。
git fetch origin codex/complete-ability-tree
git switch -c codex/complete-ability-tree --track origin/codex/complete-ability-tree
open iOS/Chronicle.xcodeproj
```

同名ブランチがあればgit switch codex/complete-ability-treeで切り替える。
全ての既習得能力も新効果を使える。途中の古い事件には後付けの敵設定を入れない。
最初から通して確認するときだけ「書き直す」を選ぶ（保存済み進行を初期化するため、必要なら先に退避する）。
