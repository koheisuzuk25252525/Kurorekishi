技名の反復だけで代表3事件を2〜3手で倒せていたため、能力の設定と戦い方の関係が薄かった。敵の次の行動を見て、黒龍で殻を破る・魔眼で標的を捉える・妨害に備えて詠唱する、という異なる攻略を可能にする。

- 代表3体に防御・不可視・詠唱妨害と、データ定義された予兆列を追加。
- 右腕・魔眼・詠唱の専用操作、共通の防御・集中、残数と詠唱段階を実装。主操作は4ボタン＋系統切替。
- 魔眼で継ぎ目を見抜けば、黒龍で通常の硬直を待たず殻を壊せる。安全な6手と危険な3手の攻略をテスト。
- 戦闘を通常の外側スクロールから分離。小画面では絵を省き、拡大文字ではスクロールを許可。短い説明、敵別の敗北ヒント、直前の詳細シートを追加。
- セーブキーと導入v4を維持。旧mainが実際に出力した途中セーブをfixtureにし、HP・残数・進行の読み込みを検証。
- 診断・戦闘方式比較・後続PR・素材仕様・配布方式比較・第三者試遊票をdocs/GAMEPLAY_REVIEW.mdに記載。
